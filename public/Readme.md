# FocusForge 🚀

Empower your learning experience. FocusForge is a feature-rich study planner, Pomodoro productivity tracker, timetable organizer, and assignment/exam manager integrated with Firebase backend authentication and storage.

## Features

- **Dashboard & Timetable**: Manage daily schedules and active subjects.
- **Pomodoro Timer**: Includes idle detection, customizable focus periods, and break overlays.
- **Assignments & Exams**: Track due dates, priority levels, and syllabus coverage.
- **Online Compilers Hub**: Quick access to web-based programming compilers.
- **Resources & Notes**: Save notes and useful links per subject.
- **Firebase Authentication & Firestore**: Secure user login and real-time cloud data synchronization.

## Setup & Deployment

1. Clone the repository.
2. Configure your Firebase credentials in `script.js`.
3. Host using GitHub Pages, Firebase Hosting, or any static web server.
